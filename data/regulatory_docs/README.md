# Regulatory Guidelines Directory

This directory stores reference guidelines and agency manuals for RAG vector indexing:
- Fannie Mae Single Family Selling Guide chapters (B3: Underwriting Borrowers, B4: Underwriting Property)
- Freddie Mac Single-Family Seller/Servicer Guide
- CFPB TRID and Ability-to-Repay / Qualified Mortgage (ATR/QM) rules
- Fair Housing Act / ECOA / HMDA reporting guidelines
